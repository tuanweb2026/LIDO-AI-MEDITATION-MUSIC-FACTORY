# Security & Compliance Policy — LIDO AI Meditation Music Factory

**Version:** 1.0.0  
**Date:** 2026-10-10  
**Status:** Enforced  

---

## 1. Zero Secret Exposure Policy

- **No Hardcoded Keys:** Credentials, tokens, or API keys must never be committed to source code or written to log files.
- **Environment Management:** Local `.env` files are excluded from source control via `.gitignore`.
- **Sanitized Logging:** All system log outputs must pass through a secret-sanitizer filter that strips patterns resembling API keys, bearer tokens, or sensitive user tokens.

---

## 2. Hard Action Restrictions (Phase 0 Enforced)

The system operates under programmatic guards that raise fatal runtime errors (`SecurityGuardViolation`) if any of the following unauthorized actions are attempted:

1. **No Content Upload / Publication:** Direct calls to video/audio uploading APIs are disabled.
2. **No Social Interaction:** Posting comments, liking videos, or sending direct messages is disabled.
3. **No Advertising Execution:** Google Ads / Meta Ads API endpoints are disabled.
4. **No Financial Transactions:** Purchasing third-party services or upgrading paid tiers is disabled.
5. **No Audiovisual Content Downloads:** Scraping or downloading YouTube video/audio streams is prohibited.
6. **No Web Scraping:** Scraping YouTube UI HTML pages is prohibited.

---

## 3. Copyright & Intellectual Property Protection

- **Melody & Composition Check:** All creative briefs generated by the system must certify that no copyrighted melodies or samples are copied from competitor channels.
- **Rights Records Audit:** Every creative brief requires an immutable `rights_records` entry certifying original work status prior to human production.
- **Audio Frequency Standards:** Concepts target general acoustic frequencies (e.g., Solfeggio 528Hz, Binaural Delta 4Hz) which are uncopyrightable natural audio specifications.

---

## 4. Input Sanitization & Threat Modeling

- **SQL Injection Prevention:** All database queries utilize parameterized SQLite bindings (`?` parameters). Direct string concatenation in SQL queries is strictly prohibited.
- **Untrusted External Data:** All video metadata obtained from external APIs or fixtures is treated as untrusted text and sanitized before rendering in Markdown reports.
